# 📚 FORENSIC AUDIO ANALYSIS TOOL - COMPLETE PROJECT GUIDE

## 🎯 PROJECT OVERVIEW

This is a **Python-based forensic audio analysis GUI application** designed for law enforcement and forensic investigators. It provides comprehensive audio analysis, AI-powered insights, multi-language transcription, and professional report generation.

```

├── 🔍 keyword_detection.py        # Crime keyword detection
```

## 🔧 CORE FILES BREAKDOWN

### 1. **gui.py** - Main Application Interface
**Purpose:** Main GUI application using PyQt6 framework
**Libraries Used:**
- `PyQt6` - Modern GUI framework for desktop applications
- `threading` - Handle long-running tasks without freezing UI
- `logging` - Application logging and error tracking

**What it does:**
- Creates the main window with professional interface
- Handles file uploads and audio recording
- Manages analysis progress and displays results
- Coordinates all other modules

### 2. **audio_processing.py** - Audio Analysis Engine
**Purpose:** Core audio processing and analysis functionality
**Libraries Used:**
- `librosa` - Advanced audio analysis and feature extraction
- `numpy` - Numerical computations and array operations
- `scipy` - Scientific computing and signal processing
- `matplotlib` - Creating waveform and spectrogram visualizations
- `soundfile` - Audio file reading and writing
- `parselmouth` - Pitch analysis and voice feature extraction
- `pydub` - Audio file format conversions

**What it does:**
- Loads and analyzes audio files (WAV, MP3, AAC, FLAC, etc.)
- Extracts metadata (duration, sample rate, channels)
- Generates waveform and spectrogram visualizations
- Performs noise analysis and quality assessment
- Detects audio anomalies and tampering signs
- Calculates pitch, formants, and voice characteristics

### 3. **speech_analysis.py** - Transcription & Emotion Analysis
**Purpose:** Convert speech to text and analyze emotions
**Libraries Used:**
- `whisper` - OpenAI's advanced speech recognition model
- `speech_recognition` - Google Speech API and fallback engines
- `transformers` - Hugging Face emotion detection models
- `torch` - PyTorch for machine learning models
- `pyannote.audio` - Professional speaker diarization
- `nltk` - Natural language processing

**What it does:**
- Transcribes audio in multiple languages (English, Hindi, Gujarati)
- Separates different speakers with timestamps
- Detects emotions in speech (happy, sad, angry, neutral)
- Analyzes speech patterns and tone
- Provides confidence scores for all detections

### 4. **keyword_detection.py** - Crime Keyword Detection
**Purpose:** Detect crime-related keywords in multiple languages
**Libraries Used:**
- `nltk` - Text processing and keyword matching
- `re` - Regular expressions for pattern matching
- `difflib` - Fuzzy string matching for variations

**What it does:**
- Maintains databases of crime keywords in English, Hindi, Gujarati
- Detects violence, drugs, weapons, theft, terrorism terms
- Performs fuzzy matching to catch variations and misspellings
- Calculates confidence scores for each detection
- Highlights keywords in transcripts with context

### 5. **forensic_ai.py** - AI-Powered Analysis
**Purpose:** Generate forensic insights using ChatGPT
**Libraries Used:**
- `openai` - OpenAI GPT API for advanced analysis
- `json` - Data formatting and API communication

**What it does:**
- Sends transcripts and analysis data to ChatGPT
- Generates professional forensic summaries
- Assesses threat levels (HIGH/MEDIUM/LOW)
- Provides investigation recommendations
- Creates executive summaries for investigators

### 6. **report_generator.py** - Professional Report Creation
**Purpose:** Generate PDF and DOCX reports with all findings
**Libraries Used:**
- `reportlab` - Professional PDF generation
- `python-docx` - Microsoft Word document creation
- `matplotlib` - Charts and visualizations in reports
- `pillow (PIL)` - Image processing for report graphics

**What it does:**
- Creates comprehensive forensic reports
- Includes waveforms, spectrograms, and analysis charts
- Formats findings in court-ready professional layout
- Generates both PDF and DOCX formats
- Embeds all evidence and analysis results

### 7. **audio_recorder.py** - Live Audio Recording
**Purpose:** Record audio directly from microphone
**Libraries Used:**
- `pyaudio` - Audio input/output and device management
- `PyQt6` - Recording dialog interface
- `threading` - Non-blocking recording process
- `wave` - WAV file creation and saving

**What it does:**
- Lists available audio input devices
- Provides professional recording dialog with VU meter
- Records high-quality audio in WAV format
- Shows real-time audio levels during recording
- Saves recordings for immediate analysis

### 8. **config.json** - Configuration Settings
**Purpose:** Store application settings and API keys
**Contains:**
- OpenAI API key for ChatGPT integration
- Language preferences (English, Hindi, Gujarati)
- Analysis options and thresholds
- Report formatting preferences
